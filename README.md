# 💖 Birthday Website

A cute pink & violet birthday website for your special someone!

## How to view it

Just open `index.html` in any browser — no setup needed. Everything (styles, animations, confetti) is in the one file.

## How to add your photos

1. Drop your photos into the `images/` folder.
2. Name them `photo1.jpg` through `photo6.jpg` (they map to the six polaroid frames in the gallery).
3. Refresh the page — the cute placeholders are replaced automatically.

PNGs work too — just update the file extensions in the `<img src="images/...">` tags inside `index.html`.

## How to personalize

- **The letter**: edit the text in the "A Little Letter For You 💌" section of `index.html`.
- **Photo captions**: edit the `.caption` text under each polaroid.
- **Reasons cards**: edit the six cards in the "A Few Reasons I Love You 🌸" section.

## Features

- 💕 Floating hearts background
- 🎉 Confetti surprise button (plus a candle-blowing wish button!)
- 💌 Love letter section
- 🌸 Six "reasons I love you" cards
- 📸 Polaroid-style photo gallery
- ✨ Smooth reveal-on-scroll animations
